# pg-mahjong

瀏覽器**台灣麻將**：十六張常見可配家規、補花、吃碰槓胡、正花／拉莊／搶槓、你＋三名 AI（可託管）。純前端，無建置步驟；**mobile-first**。

名稱與介面為原創小品，致敬台灣十六張麻將玩法；家規預設見 [`RULES.md`](./RULES.md)。**非**單一官方競技規程。

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。

## 操作

| 操作 | 說明 |
| --- | --- |
| **開局** | 發十六張、補花、莊家摸牌（僅待機） |
| **家規** | 起胡、拉莊、搶槓、花牌、底／台金等 |
| **託管** | AI 代打；再按取消立刻接手 |
| 點牌抬起 → 再點打出 | 打牌不佔底欄；摸進的牌單獨放在「新」格 |
| **吃／碰／槓／胡／略過** | 叫牌窗（含搶槓胡）；只出現當下合法的動作 |
| **暗槓／加槓** | 多組時在操作列上方以牌組縮圖選 |
| **重來** | 頁內確認；保留累積分與家規 |

## 畫面（資訊層級）

- **單屏牌桌：** 頁面不整體捲動；牌河在牌桌內捲，手牌與操作列固定可及。
- **牌桌中央：** 誰的回合 ＋ 最新打出的牌（含打牌者），落牌有短動畫。
- **底部操作列：** 只在叫牌或可胡／槓時出現；打牌靠雙擊手牌，不常駐「打出」。順序＝胡 ＞ 槓 ＞ 碰 ＞ 吃，**略過**降階；吃／槓的組合選單就在同一層。
- **聽牌提示：** 手牌上方以**牌面**列出聽哪幾張，數字＝該張還沒現身的剩餘張數（0 張＝已絕張）。
- **對手：** 以牌背呈現手牌張數，剛摸進的牌另外分開；碰吃槓與花牌照方位攤在各家位置。
- 對局中收起標題與旁白，狀態改由牌桌中央與操作列承擔（旁白仍留給螢幕閱讀器）。

## 規則摘要（預設）

- 牌組 144；死牆 16；槓／補花從死牆補
- 叫牌：胡 ＞ 碰／明槓 ＞ 吃（僅下家）；一炮一響
- 過水；加槓可解過水；加槓可被搶
- 流局臭莊連莊；拉莊 `2N+1`
- 計分：`底 + 台 × 台金`；自摸三家付、放槍一家付
- 詳見 [`RULES.md`](./RULES.md)
